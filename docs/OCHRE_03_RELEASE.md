# ØchreCL 0.3.0-alpha.1 测试构建

## 本轮完成

- 服务器实例 Java 选择行固定高度，避免提示重叠。
- 下载任务在主页显示悬浮球；启动中使用自绘轨道粒子，不再使用系统进度圆圈。
- 三张内置图片已更换为用户提供的星轨古堡、海岸落日、雨林光影；保存旧图片 ID 兼容配置。背景列表第一项为“跟随主题色（默认）”。
- 沉浸式透明可复用内置/已选图片，退出时还原原背景与透明度。为手选图片生成独立文件，避免覆盖原图片。
- 服务器部署与导入按实际步骤推进，当前阶段进度和右侧记录分开。
- 地址选择器提供本地、真实网络接口的局域网地址、已配置 OpenFrp/FRP 地址及手填公网地址。公网入站未验证时不声称已连通。
- 网络检测移到服务器页顶部，与异常监测/应急独立；链路检测结果独立呈现。
- 附加项筛选在宽窗口一行，普通窗口两行，极窄窗口纵向，固定 34px 控件高度。
- 首次启动为欢迎、外观、游戏目录导入、简短动画指南四步；固定底部进度与导航。目录列表为圆角卡片，固定圆形＋按钮位于卡片内。
- 顶部增加导入服务器：复制到独立目录，检查世界锁、符号链接、复制期间变动和 JAR 入口；不执行启动脚本，不修改原目录，不代为同意 EULA。
- 主页只在实际 Minecraft 版本为 26.x 时显示“操作游戏”。

## 游戏桥接

- 可选安装提示，逐实例明确授权；以 Java agent 挂载，不改写游戏 JAR，不要求玩家安装 Fabric/Forge。
- 仅绑定 127.0.0.1，随机逐次启动授权令牌保存在私有配置，不出现在启动命令行；协议具有版本与能力发现，有限帧长、并发和超时，拒绝未知操作。
- 已在独立临时目录实际启动 26.2 原版主类（无加载器），验证握手、设置读取、主音量/亮度/视野/渲染距离实时变更和保存，验证错误令牌及未知指令拒绝。只用虚拟离线账号，不修改真实实例与世界。
- 26.x 为目标家族，目前只有 26.2 原生实测；其他 26.x 仍需逐版本验证，不兼容 API 返回不可用。该组件不是可随意放进 mods 的通用 Fabric JAR，由启动器挂载。
- 安装后需重启该游戏。可在操作游戏中检查连接、停用组件；当前进程中的组件在游戏退出后完全解除。
- 脚本页当前支持新建、导入、粘贴、编辑、保存文本；脚本语言、条件/循环、移动、自动瞄准、背包与周边实体等完整脚本 API 留待下一轮确定，当前不执行脚本。

## 更新器

- 关于 → 启动器更新，官方源固定为 GitHub Fishyra/OchreCL Releases。
- 下载 OchreCL-update.jar，使用 GitHub SHA-256 与大小校验；用户目录原子切换，下次启动加载；损坏文件回退内置程序。
- 独立引导器验证过真实新镜像加载与损坏拒绝，更新资产使用固定文件名 `OchreCL-update.jar`；安装前必须通过 GitHub 提供的 SHA-256、大小与 JAR 结构校验。
- 旧版完整应用未带新引导器，需先安装本构建。新 Java/JavaFX/原生依赖仍走完整安装包。

## 验证边界

macOS 原生客户端桥接实测通过；Windows 与 Linux 尚未原生实测。网络诊断只代表测试路径，异常监测不是 DDoS 防护。微软授权仍需项目自己的有效 Client ID。
