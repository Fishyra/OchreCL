## Øchre Script 首个可执行测试版

本次更新加入英文脚本运行器与代码编辑快捷操作，并新增 macOS Intel（x86_64）安装包。官网下载按钮直接获取安装包，不需要提取码。

### 新增
- 英文关键字与 API、大括号、分号、类型变量、if/else、while、for、列表遍历、s/ms/blocks/deg 单位与命名参数。
- 脚本权限按次授权：读取、设置、视角、移动、攻击分别选择；导入和保存不会自动执行。
- 停止按钮、关闭工作区取消、执行预算和独立输入租约，避免异常后留下按住的移动键。
- 语言、位置、视角、时钟、背包和附近玩家读取接口，以及声音/视频设置接口；视角、前进、疾跑、攻击为实验接口。
- 自动配对括号/引号、选中包裹、成对删除、自动缩进、行号、批量注释、复制/移动行、查找、原生撤销重做。
- 脚本列表与编辑/输出区域采用主题圆角卡片；输出默认折叠，适配短窗口。
- 新增 Intel Mac DMG，保留 Apple Silicon DMG、Windows x64 ZIP、Linux x64 TAR.GZ。

### 升级
0.3.0-alpha.1 用户可在“关于 → 启动器更新”检查本次更新。更早版本先安装完整包。更新后如需游戏脚本接口，请在“操作游戏”点击“安装/修复组件”，并重新启动游戏，以加载新版桥接。

macOS 安装包分别对应 Apple Silicon 与 Intel，请按芯片选择。Intel 包要求 macOS 11 或更高版本；不是 32 位 x86 包。安装包尚未进行 Apple 开发者签名、公证或 Windows 发行签名。

### 验证与限制
28 项相关单元测试通过；独立假客户端契约测试覆盖输入租约、切换式疾跑释放、目标选择、背包及视角。原版 26.2 的原生验证覆盖桥接认证、设置读写与未进入世界时拒绝动作。

**移动、攻击、背包等新接口尚未完成真实世界内的端到端验证；Intel Mac、Windows、Linux 包尚未原生实测。其他 26.x 版本仍需逐版本适配。** 不将接口接通等同于所有游戏场景已验证。

寻路 walk_to 与精确手臂定位暂不可用，会明确报错，不用传送或身体中心代替。当前编辑器为纯文本，不含语法着色、符号补全、断点调试或自定义函数。脚本不能访问任意文件、进程或网络，不绕过服务器权限。微软登录仍需有效的独立 Client ID。

源代码与脚本说明随版本标签提供；安装文件校验见 SHA256SUMS.txt。OchreCL-update.jar 是启动器内部更新资源，不是独立安装包。
